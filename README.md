# 贴吧美化 · 用户与关键词屏蔽

一个运行在 Chrome + Tampermonkey 上的百度贴吧辅助脚本：屏蔽不想看到的用户和关键词，折叠回复、隐藏主题贴，并支持 CSV 导入导出与默认「最新 / 发布」排序。

- **版本**：1.7.2
- **作者**：黑渊玄
- **脚本文件**：`tieba-beautify.user.js`

---

## 功能

1. **屏蔽用户**
   - 贴吧列表页：该用户发布的主题贴直接从页面移除。
   - 帖子详情页：该用户的回复折叠成一条提示「已屏蔽用户发帖，是否展示内容」，可点「展示」正常阅读，或点「不展示」保持收起。
   - 用户名和等级标签右侧新增「屏蔽」按钮，帖子列表、帖子楼层、悬浮卡均可使用；点击后可填写原因（可留空），确认即加入屏蔽名单。
2. **屏蔽备注**
   - 添加用户时可填写屏蔽原因。
   - 帖子详情页中，备注会以全角括号形式显示在用户名右侧，例如：`某用户（广告刷屏）`。
3. **屏蔽关键词**
   - 标题命中关键词的主题贴一律隐藏。
   - 同样支持填写屏蔽理由，并在「名单管理」页统一管理。
4. **CSV 导入 / 导出**
   - 一键导出全部屏蔽用户与关键词，保存为 CSV 文件。
   - 在另一台电脑导入即可同步；导入只合并且不会清空现有列表。
5. **默认最新发帖排序**
   - 开关开启后，打开任意贴吧会自动切换到「最新」标签。
   - 新版页面还会在「看贴排序」中自动选择「发布」，按发帖时间排序。
   - 手动切换其他标签后不会被反复改回。
6. **排版无空洞**
   - 被隐藏的主题贴不占位置，后续帖子自动衔接。
   - 被折叠的回复只保留一条紧凑提示，下方楼层自动上移。
7. **统一设置入口**
   - 页面顶部自己的头像右侧新增「贴吧美化」按钮，点击展开全部设置。
   - 按钮采用固定悬浮定位，向下滚动页面时不会消失，始终停在顶部右上角。
   - 底部「关于插件」是独立页面，显示作者、版本、运行环境与数据存储方式。
8. **独立名单管理页**
   - 设置首页不再铺开全部名单，只保留添加表单和数量统计。
   - 点击「名单管理」进入独立页面，以表格展示用户名 / 关键词、备注和「移除」操作。
   - 名单表格支持单独滚动，名单较长时不会撑高设置面板。

### 新版贴吧适配

贴吧已逐步切换到新的信息流页面（帖子以卡片形式展示，不再使用旧版的 `thread_list` 结构）。脚本同时识别两种页面：

- 旧版列表：按 `thread_list` / 帖子标题 / 作者链接处理。
- 新版信息流：按帖子卡片中的主题链接或作者主页链接定位整张卡片，隐藏被屏蔽用户或命中关键词的卡片。
- 新版用户名结构是 `.head-name`（位于 `.name-info` 内），等级用图标展示而不是 `Lv.8` 文字；「最新」标签的真实链接参数是 `tab=503`。
- 新版帖子页的回复是 `.pb-comment-item`，楼中楼是 `.pb-lzl-item`，回复正文是 `.comment-content`，主题正文是 `.pb-content-wrap`；1.7.0 起按这些结构折叠被屏蔽用户的回复。

新版页面如果调整结构导致识别失败，可在脚本的「关于插件」页确认版本为 1.7.2 或更高。

## 安装

1. 在 Chrome 中安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. 点击 Tampermonkey 图标 → **添加新脚本**。
3. 删除编辑器中的默认模板，粘贴 `tieba-beautify.user.js` 的全部内容。
4. 按 `Ctrl + S` 保存。
5. 打开百度贴吧的列表页或帖子页，头像右侧会出现「贴吧美化」按钮。

也可以直接把 `.user.js` 文件拖进 Chrome 窗口，按提示安装。

## 使用

### 屏蔽用户

1. 点击头像右侧的「贴吧美化」。
2. 在「屏蔽用户」中输入用户名。
3. 在下方备注框填写屏蔽原因（可选，会显示在回复用户名右侧）。
4. 点击「添加」。

添加后可在「名单管理」中查看完整名单。

### 用户名旁一键屏蔽

1. 帖子列表、帖子楼层、悬浮卡里的用户名 / 等级右侧都有「屏蔽」按钮。
2. 点击后填写原因（可留空），确定即加入名单。
3. 按钮变为「已屏蔽」，页面内容同步隐藏。
4. 已被屏蔽的用户，刷新页面后按钮仍显示「已屏蔽」并禁用，不会重复弹出原因输入框；从名单移除后会恢复为「屏蔽」。

脚本优先按新版 `.head-name` 定位用户名，旧版或其他版式再按等级标签兜底；点击「屏蔽」不会跳转个人主页。

### 屏蔽关键词

在「屏蔽关键词」中输入词或短语，可按需填写备注，然后点击「添加」。主题贴标题包含该词时会被隐藏。

匹配不区分英文大小写，并会做全角/半角归一化处理。

### 名单管理

1. 点击设置首页的「名单管理」，进入独立名单页。
2. 页面分为「屏蔽用户」和「屏蔽关键词」两张表，列分别为：用户名 / 关键词、备注、操作。
3. 点击行末「移除」即可取消屏蔽，页面会立即恢复对应内容。
4. 表格下方「＋ 添加用户 / ＋ 添加关键词」会返回设置页并定位到对应输入框。

设置首页只显示数量统计，不再铺开完整名单；名单较长时表格内部单独滚动。

### 导出与导入

- **导出 CSV**：生成包含全部用户与关键词的文件，可直接用 Excel / WPS 打开。
- **导入 CSV**：选择此前导出的文件，自动合并并去重；已有条目会更新备注。

CSV 使用 UTF-8 BOM 编码，Excel 打开中文不乱码；导入同时兼容 GBK 编码的 CSV。

### 默认最新排序

打开「默认最新发帖排序」开关后，进入贴吧列表页会自动切到「最新」，并在新版页面的「看贴排序」中选择「发布」。开关状态会保存在本机。

## CSV 格式

```csv
类型,名称,备注
用户,示例账号,广告刷屏
关键词,示例词,违规内容
```

- 第一列：`用户` 或 `关键词`（也兼容 `user` / `keyword`）。
- 第二列：用户名或关键词。
- 第三列：备注，可为空。
- 含逗号、引号或换行的内容需用双引号包裹，导出文件会自动处理。

## 数据与隐私

- 所有屏蔽数据保存在 Tampermonkey 的本地存储中，不会上传到任何服务器。
- 脚本不会读取账号密码、Cookie 或聊天内容。
- CSV 文件只保存在你选择的本地位置。
- 清除浏览器数据、卸载扩展或更换浏览器会导致本地名单丢失，建议定期导出备份。

---

## 兼容性与已知限制

- 适用于百度贴吧的论坛列表页和帖子详情页；贴吧改版导致页面结构变化时，脚本可能需要更新选择器。
- 新版信息流页面通过页面中的主题链接 / 作者主页链接定位卡片；两种链接都不存在的特殊版式可能无法识别。
- 屏蔽是浏览器本地行为，不会影响其他用户或服务器端内容。
- 跨电脑同步需要手动导出 / 导入 CSV。

## 常见问题

**Q：按钮没有出现在头像右侧？**
A：先刷新页面。若未登录或贴吧头部尚未渲染，按钮会暂时固定在右上角；登录并刷新后会回到头像右侧。

**Q：添加后列表没有变化？**
A：确认当前页面是贴吧列表页或帖子页，并稍等片刻；列表异步加载时脚本会自动重新扫描。

**Q：换了电脑，名单是空的？**
A：屏蔽数据保存在本机。请在旧电脑「导出 CSV」，在新电脑「导入 CSV」。

**Q：开启了最新排序，但页面还是旧顺序？**
A：确认开关已开启并刷新页面。新版页面会自动点击「最新」和「看贴排序 → 发布」；若页面结构变化导致按钮未被识别，请确认「关于插件」页显示的版本为 1.7.0 或更高。
